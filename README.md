# Payment Gateway – Multi Method Processing

## Overview
This project is a simplified payment gateway similar to Razorpay/Stripe.
It supports merchant order creation and customer payments using UPI and Cards.

## Tech Stack
- Backend: Node.js + Express
- Database: PostgreSQL
- Frontend: HTML/CSS (Dashboard + Checkout)
- Containerization: Docker & Docker Compose

## Services & Ports
- API: http://localhost:8000
- Dashboard: http://localhost:3000
- Checkout: http://localhost:3001

## Running the Project
```bash
docker-compose up -d
